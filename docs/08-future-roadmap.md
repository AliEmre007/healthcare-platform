# Future Roadmap

## Frontend Plan

Build a React, TypeScript, Vite, Tailwind, React Query, React Hook Form, and Zod frontend after the backend core is stable.

## Mock MEDULA Adapter

Represent billing/provision workflows using fake sandbox responses only.

## Mock MHRS Adapter

Represent appointment integration workflows using mock clients only.

## Mock HL7 Message Processor

Parse and produce educational HL7 v2-style messages without connecting to live systems.

## Mock DICOM/PACS Adapter

Represent imaging order and study metadata flows without storing real images or connecting to PACS.

## Prometheus/Grafana

Add metrics and dashboards for service health, request rates, and latency.

## Nginx Reverse Proxy

Add reverse proxy configuration for local and deployment environments.

## Deployment to EC2

Document secure VM provisioning, environment management, Docker deployment, TLS, backups, and logging.

## Kubernetes Future Option

Explore manifests or Helm charts after Docker deployment is stable.
