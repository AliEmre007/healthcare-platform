# Project Scope

## What This Project Is

Secure Hospital Management System with FHIR-style API and DevOps Deployment is an educational, portfolio-grade backend platform. It demonstrates healthcare-aware domain modeling, secure API design, modular backend architecture, persistence, testing, documentation, and deployment practices.

## What This Project Is Not

- Not a production HBYS/HIS.
- Not a certified FHIR server.
- Not a medical device.
- Not a billing, prescribing, identity verification, PACS, LIS, or national healthcare gateway.
- Not connected to MHRS, MEDULA, e-Nabiz, Saglik.Net, MERNIS, SGK, DICOM/PACS, laboratory devices, or any real external healthcare system.

## MVP Scope

- Secure authentication and role-based authorization.
- Patient, practitioner, appointment, encounter, clinical note, diagnosis, lab, medication request, and audit log modules.
- FHIR-style read APIs for selected resources.
- PostgreSQL and Redis-backed local development environment.
- Tests, CI, and DevOps runbook.

## Future Scope

- React frontend.
- Mock national healthcare and interoperability adapters.
- Mock HL7 v2 processor.
- Mock DICOM/PACS adapter.
- Monitoring, reverse proxy, cloud deployment, and Kubernetes exploration.

## Privacy Disclaimer

Use only fake or synthetic data. Do not enter, import, store, transmit, or publish real patient data.
